# student-lessons

## Переходящий остаток в личном кабинете

В поле `subscription` каждого месяца вводится **только количество новых оплаченных уроков** за этот месяц. Остаток прошлого месяца добавляется автоматически; вручную включать его в новый абонемент не нужно.

Формула: остаток на начало месяца + новые уроки − количество уникальных проведённых дат. Пустой абонемент и отсутствующий месяц не обнуляют остаток. Отрицательный баланс также переходит дальше и погашается последующей оплатой. До появления первого абонемента или проведённого урока показывается «—».

Баланс каждый раз вычисляется из истории до выбранного месяца. Перенос не записывается в исходные данные, поэтому переключение месяцев, перезагрузка и автообновление не начисляют уроки повторно. Изменение старого абонемента или даты пересчитывает последующие остатки. Будущие оплаты на прошлые месяцы не влияют.

Если остаток уже был вручную добавлен в `subscription` следующего месяца, уберите из этого поля ручной перенос, оставив новые покупки: отличить его от новой оплаты по существующему формату данных невозможно.

Шифрование v1, личные ссылки, опубликованные записи и история занятий не меняются. Красная пометка показывает входящий перенос и положительный остаток, переданный из завершённого месяца дальше.

Проверка (Node.js 18+):

```sh
node --test tests/carryover.test.cjs
```

Тесты используют вымышленные данные, включая зашифрованную запись с AES-CBC/HMAC и личную ссылку. Ключи реальных учеников не требуются.
